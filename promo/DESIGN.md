## โมเดลเสื้อ (ขั้นที่ 1)

สคริปต์ `blender/tshirt.py` (Blender 4.5 LTS headless) ทำตามขั้นนี้
1. **ตัดแพทเทิร์น** 4 ชิ้น ไซซ์ M: ตัวหน้า/ตัวหลัง (รอบอก ~109 ซม., ยาว 71 ซม., ชายบานนิดๆ, คอหน้าลึก 9 ซม./คอหลัง 2 ซม.)
   และแขน 2 ข้าง (หัวแขนยาวกว่าวงแขน ~1 ซม. เป็น ease) — mesh แต่ละชิ้นเป็น quad grid แบบ Coons patch
   ให้จำนวนจุดบนตะเข็บที่เย็บติดกันเท่ากันพอดี
2. **วางรอบหุ่นล่องหน** (ลำตัวทรงรี + คอ + แขนกาง 45°) แล้ว **เย็บด้วย sewing springs** ของ cloth sim
   ปิดแรงโน้มถ่วงช่วงเย็บ แล้วค่อยเปิด ให้ผ้าค้างบนไหล่จนเกิดรอยยับ (ผ้าขยาย 2.5% + bending ต่ำ = ลอนนุ่มตามธรรมชาติ)
   จากนั้นรวมจุดที่เย็บเป็นจุดเดียว (ช่องว่างตะเข็บหลัง sim: median 0.4 มม.)
3. **Subdivision** 1 ระดับ + **ร่องตะเข็บ** (กดตะเข็บไหล่/ข้าง/วงแขนลง 1.1 มม.) + ตะเข็บเดินด้ายที่ชายและปลายแขน
4. **ชาย/ปลายแขนพับขอบ**: ผ้าม้วนเข้าในเป็นตัว U แล้วทาบขึ้นไป ~2 ซม. (ชิ้นแยก)
5. **คอยางยืดริบ** แยกเป็นอีกชิ้น สูง 1.8 ซม. หนา ~3.8 มม. ใช้วัสดุ `rib`
6. **Solidify 2 มม.** ทั้งตัว (ปิด even-offset กันจุดพุ่งตรงรอยพับคม), smooth shading
7. UV = แพทเทิร์นแบน (1 หน่วย UV = ผ้า 1.15 ม.) สำหรับ normal map ลายผ้า, คอเสื้อ UV เป็นเมตร
8. Export GLB + Draco ไม่เกิน 60k tris

**เสื้อบนแท่น**: เอาเสื้อที่เย็บแล้ววางนอนหงาย ปล่อยลงบนแท่นรัศมี 30 ซม. สูง 55 ซม. (cloth sim + self collision)
ใน glb จุด origin = กึ่งกลางผิวบนของแท่น → ในฉากสตูดิโอวางบนทรงกระบอกรัศมี 0.30 ที่ y = 0.55

**ด่านตรวจ** (ภาพใน `qa/`): render Cycles 4 มุมใต้ไฟสตูดิโอ
- ความหนาที่คอและปลายแขน: เห็นชัด (`model-closeup-collar.png`, `model-closeup-sleeve.png`)
- รอยยับ + เงาในรอยยับ: เห็นชัด (`model-front.png`, `model-34.png`)
- มองข้างไม่แบน: ตัวเสื้อลึก ~27 ซม. (`model-side.png`)
- ปรับ 3 รอบ: (1) รอยยับน้อย ไฟจ้า → (2) ผ้าขยาย 3.5% ยับเป็นตุ่มเล็กเกิน → (3) ค่ากลาง + ไฟข้าง ผ่าน

## วัสดุและไฟ (ขั้นที่ 2)

**ผ้าฝ้าย** `MeshPhysicalMaterial`: roughness 0.85, sheen 1, sheenRoughness 0.8, sheenColor = สีผ้าสว่างขึ้นนิด
(ผ้าสีเข้มใช้ sheen ใกล้สีผ้า ไม่งั้นดูซีดเป็นเทา), normal map ลายถักซิงเกิลเจอร์ซีย์ที่สร้างด้วยโค้ด
(24 คอลัมน์ × 32 แถวต่อ 2 ซม., normalScale 0.55) — คอเสื้อใช้ลายริบ 1×1 (normalScale 0.9)

**ไฟ**: Environment = HDRI `studio_small_03` (ไฟล์เดียวกับ preset `studio` ของ drei เก็บไว้ในเครื่อง)
+ key light นุ่ม (directional + PCF soft shadow, เงาตกในรอยยับ) + rim light ด้านหลังให้ขอบเสื้อสว่าง
เงาพื้นใช้ `ContactShadows` (DROP 01, สตูดิโอ) + spot shadow ในสตูดิโอ

**ภาพรวม**: tone mapping ACES Filmic (ผ่าน postprocessing `ToneMapping`), N8AO (เงาในซอก), bloom นิดเดียว,
vignette, depth of field ในฉากที่กล้องอยู่ใกล้ (ทุ่งผ้า, สตูดิโอ) — DOF โฟกัสตามเสื้อทุกเฟรม

**การขยับ**: เสื้อลอยขึ้นลง ±2 ซม. และหมุนช้าๆ ทั้งก้อน (ไม่บิด vertex)

## คลิป (ขั้นที่ 4)

- ฉาก: โน้ตบุ๊กสร้างเอง (อะลูมิเนียม space gray, คีย์บอร์ด, แทร็กแพด) บนโต๊ะ `MeshReflectorMaterial`
  ห้องมืด แสงหลักมาจากจอ (RectAreaLight สีตามค่าเฉลี่ยของหน้าเว็บแต่ละเฟรม — ตอนเข้าฉากสว่างคีย์บอร์ดจะสว่างตาม)
- จอโน้ตบุ๊กใช้ `VideoTexture` จาก `screen.webm` (VP9 ทุกเฟรมเป็น keyframe เพื่อ seek ได้ตรงเฟรม)
- กล้องดันเข้าช้าๆ ตลอดคลิป (ระยะ 1.50 → 1.06 ม., fov 28°)
- ข้อความบน: `POV: ร้านเสื้อของคุณ / มีเว็บแบบนี้ 😮‍💨` ตลอดคลิป (top 250px, เว้นขอบขวา 130px)
- การ์ดปิด 12.98–15.0 วิ: "รับทำเว็บร้านเสื้อผ้า" + ปุ่ม "ทักแชทได้เลย →"
  **ที่ว่างสำหรับใส่ชื่อร้าน: x 90–950, y 640–820 (px ในเฟรม 1080x1920)** เว้นว่างไว้ ไม่มีอะไรทับ
- ไม่มีตัวหนังสือในแถบล่าง 380px และขอบขวา 130px (กันปุ่ม TikTok บัง)

### Render
ไม่ได้ใช้ hyperframes: งานนี้แทบทั้งหมดเป็น WebGL ที่ต้องเดินเวลาเองทีละเฟรม (R3F `frameloop="never"` + `advance()`)
และ seek วิดีโอเป็น texture ทุกเฟรม ซึ่งไม่ใช่สิ่งที่ hyperframes ออกแบบมา (เน้นคอมโพส HTML/GSAP)
จึงใช้ทางสำรองตามบรีฟ: Playwright จับทีละเฟรมแบบ deterministic → ffmpeg
Chromium headless ใช้ SwiftShader (`--use-angle=swiftshader --enable-unsafe-swiftshader`)

```
cd promo/blender && blender -b --factory-startup --python tshirt.py -- sim drape export qa
cd promo/web && npm i && cp ../models/*.glb public/models/ && npx vite build
node capture/render-scenes.mjs          # เฟรม 3D ของ 5 ฉาก -> .frames/<scene>/
node capture/compose-screen.mjs         # ประกอบหน้าเว็บ -> out/screen.mp4 + public/screen.webm
npx vite build                          # เอา screen.webm เข้า dist
node capture/render-laptop.mjs          # ฉากโน้ตบุ๊ก -> .frames/laptop/
../tools/finish.sh                      # -> out/promo-nomusic.mp4, out/promo.mp4
```
