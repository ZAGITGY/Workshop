## ทำไมต้องทำใหม่
รอบที่แล้วเสื้อเป็นรูป SVG แปะบนแผ่นแบน ออกมาเหมือนกระดาษพับเป็นรูปเสื้อ ดูไม่ออกเลยว่าเป็น 3D
รอบนี้เสื้อต้องเป็น**โมเดล 3D จริง** มีความหนา มีรอยยับ มีตะเข็บ มีเงา
**ห้ามใช้รูป 2D หรือแผ่น plane แทนตัวเสื้อเด็ดขาด**

## กติกา
- ทำทุกอย่างในโฟลเดอร์ `promo/` เท่านั้น งานรอบก่อนในโฟลเดอร์นี้ลบหรือเขียนทับได้ทั้งหมด ห้ามแตะไฟล์อื่นใน repo
- ทำบน branch ใหม่ แล้วเปิด PR ห้าม push เข้า main ตรงๆ
- ใส่ `promo/music/`, `*.mp4` และไฟล์ .blend ใหญ่ๆ ไว้ใน `.gitignore`
- แบรนด์สมมติชื่อ **MOK STUDIO** ห้ามใช้โลโก้หรือชื่อแบรนด์จริง ฟอนต์ใช้ของฟรีจาก Google Fonts เท่านั้น
- อารมณ์และจังหวะของคลิปให้ดูจาก `reference/` แต่ห้ามก๊อป layout ข้อความ หรือ asset ของเว็บนั้น
- รอบก่อนมีบางส่วนที่โอเคแล้ว คือสไตล์ตัวหนังสือ เมนูบน และฉากทุ่งผ้า ถ้าตรงกับสเปกด้านล่างก็ใช้แนวเดิมต่อได้

## ขั้นที่ 1: ปั้นโมเดลเสื้อเอง (ต้องผ่านขั้นนี้ก่อน ถึงจะไปขั้นต่อไปได้)
ใช้ Blender ผ่าน Python จะ `pip install bpy` หรือรัน blender แบบ headless ก็ได้

**วิธีทำ**
1. ตัดแพทเทิร์นเสื้อยืดเป็น mesh: ตัวหน้า ตัวหลัง แขนสองข้าง
2. เย็บต่อกันด้วย cloth simulation (ใช้ sewing springs)
   แล้วให้เสื้อพองเป็นทรงเหมือนมีคนใส่อยู่ หรือให้แขวนอยู่บนไม้แขวน จนมีรอยยับตามธรรมชาติ
3. ใช้ Solidify หนาประมาณ 2 มม. ให้ผ้ามีความหนา
4. คอเสื้อเป็นยางยืดแยกเป็นอีกชิ้น ปลายแขนกับชายเสื้อให้พับขอบ
5. ใส่ Subdivision กับ smooth shading ตะเข็บทำเป็นร่องบางๆ
6. ทำ UV ไว้สำหรับใส่ normal map ลายผ้า
7. ลด poly ให้พอดีกับเว็บ ไม่เกินประมาณ 60k tris แล้ว export เป็น `promo/models/tshirt.glb` (ใช้ Draco ได้)

**ชิ้นที่สอง:** `promo/models/tshirt-draped.glb`
ปล่อยเสื้อลงมาด้วย cloth sim ให้ตกพาดลงบนแท่นทรงกระบอก ใช้ในฉากสตูดิโอ

**ถ้ามีเวลาเหลือ:** ทำ `hoodie.glb` แบบเดียวกัน ถ้าไม่ทันให้ใช้เสื้อยืดตัวเดิมเปลี่ยนเป็นสีอื่น

**ด่านตรวจก่อนไปขั้นต่อไป**
render ภาพหมุนรอบเสื้อ 4 มุม (หน้า ข้าง หลัง และมุม 3/4) ภายใต้ไฟสตูดิโอ
เก็บไว้ที่ `promo/qa/model-*.png` แล้วเปิดดูเอง ต้องผ่านทุกข้อ:
- เห็นความหนาของผ้าตรงคอและปลายแขน
- เห็นรอยยับ และในรอยยับมีเงา
- มองจากด้านข้างแล้วเสื้อต้องไม่แบน
ข้อไหนไม่ผ่าน ให้แก้แล้วลองใหม่ ได้สูงสุด 3 รอบ

**ถ้าปั้นเองแล้วไม่สวย หรือติดตั้ง Blender ไม่ได้ ให้หาโมเดลฟรีจากเน็ตแทน**
- หาเฉพาะที่โหลดได้เลยโดยไม่ต้องล็อกอิน เช่น Poly Pizza หรือ repo บน GitHub
- license ต้องเป็น CC0 หรือ CC BY เท่านั้น ถ้าเป็น CC BY ให้จดชื่อคนทำกับลิงก์ไว้ใน `promo/CREDITS.md`
- ห้ามใช้โมเดลที่ไม่บอก license หรือห้ามใช้เชิงพาณิชย์
- โมเดลที่หามาต้องผ่านด่านตรวจข้างบนเหมือนกัน
  ใช้ Blender ปรับต่อได้ เช่น จัดทรง ใส่ Solidify หรือใช้ cloth sim ให้เสื้อพาดบนแท่น
- ถ้าหาแบบที่โหลดได้ไม่เจอเลย ให้หยุดแล้วบอกเบส เดี๋ยวเบสโหลดจาก Sketchfab มาให้ใส่ไว้ที่ `promo/models/`

**ห้ามกลับไปใช้แผ่นแบนเด็ดขาด ไม่ว่ากรณีไหน**

## ขั้นที่ 2: วัสดุและไฟ (ใน three.js)
ใช้ react-three-fiber + drei

**วัสดุผ้าฝ้าย** ใช้ `MeshPhysicalMaterial`
- roughness ประมาณ 0.85
- เปิด sheen (sheen 1, sheenRoughness ประมาณ 0.8)
- ใส่ normal map ลายทอผ้าละเอียดๆ ให้เห็นเนื้อผ้าตอนกล้องเข้าใกล้
- ต้องไม่ดูเป็นพลาสติกหรือมันวาว

**ไฟ**
- Environment preset `studio`
- key light นุ่มๆ หนึ่งดวง กับ rim light ให้ขอบเสื้อสว่าง
- เงาใช้ ContactShadows หรือ AccumulativeShadows

**ภาพรวม**
- tone mapping แบบ ACES หรือ AgX
- post-processing เบาๆ: vignette, bloom นิดเดียว และ depth of field ในฉากที่กล้องอยู่ใกล้

**การขยับ**
- เสื้อลอยขึ้นลงช้าๆ และหมุนนิดหน่อย
- ห้ามบิด vertex จนทรงเสื้อเพี้ยน

## ขั้นที่ 3: หน้าเว็บจำลองบนจอ (1440x900 มี 5 ฉาก)
หน้าเว็บนี้ยังไม่ต้องเป็นเว็บจริง ทำเป็นแอนิเมชันที่ดูเหมือนเว็บจริงกำลังถูกเลื่อนลง
มีเมนูบางๆ อยู่บนสุดทุกฉาก และมีตัวนับฉาก 01/05 ที่มุมขวาล่าง

1. **Hero (มืด)** หมอกสีเขียวอมฟ้าเข้ม คำว่า MOK ตัวใหญ่จางๆ อยู่ด้านหลัง
   เสื้อยืดสีขาวลอยอยู่กลางจอ ตัวใหญ่ได้ ให้เห็นรอยยับชัด
   มุมซ้ายล่างเป็นหัวข้อภาษาไทย
2. **ทุ่งผ้า (มืด)** กล้องบินต่ำเลียดผืนผ้าใหญ่ที่ยับเป็นลอนเหมือนเนินเขา เสื้อลอยผ่านไป
   มี callout เส้นบางๆ ชี้ไปที่เสื้อ เช่น "คอตตอน 100%"
3. **DROP 01 (สว่าง)** พื้นหลังเปลี่ยนเป็นสีขาวนวล มีคำว่า DROP 01 ตัวใหญ่สีเทาอยู่ด้านหลัง
   เสื้อสองตัวคนละสีลอยอยู่หน้าตัวหนังสือ ขอบซ้ายขวาใส่ตัวเลขสเปก เช่น "240 GSM" และ "S–XL"
4. **สตูดิโอ (มืด)** ห้องสีเทาเข้ม สปอตไลต์ส่องลงมาเป็นวงแสงบนแท่น
   บนแท่นคือ `tshirt-draped.glb` ห้ามใช้กล่อง และห้ามมีจุดขาวเบลอลอยอยู่
5. **ปิดท้าย** ข้อความใหญ่ "WEAR IT QUIET" กับปุ่ม "สั่งซื้อทาง LINE"

ฉากต้องต่อกันแบบลื่นๆ เหมือนเลื่อนจอจริง ห้ามตัดภาพกระโดด

## ขั้นที่ 4: คลิป
- 1080x1920 (9:16) ยาว 15 วินาที 30fps MP4 H.264
- ฉาก: โน้ตบุ๊กวางบนโต๊ะที่สะท้อนเงา (`MeshReflectorMaterial`) แสงมืดแบบ cinematic กล้องค่อยๆ ดันเข้า
  บนจอโน้ตบุ๊กคือหน้าเว็บจำลองจากขั้นที่ 3 (ใช้ video texture)
- render ด้วย hyperframes (https://github.com/heygen-com/hyperframes) ถ้าใช้ได้
  ถ้าไม่ได้ ให้ใช้ Playwright จับทีละเฟรมแบบ deterministic แล้วต่อเป็นวิดีโอด้วย ffmpeg
  ถ้า headless เปิด WebGL ไม่ได้ ให้ลอง `--use-angle=swiftshader`
- ข้อความบนคลิปอยู่ด้านบนตลอดทั้งคลิป: `POV: ร้านเสื้อของคุณมีเว็บแบบนี้ 😮‍💨`
- 2 วินาทีสุดท้ายเป็นการ์ดปิด: "รับทำเว็บร้านเสื้อผ้า · ทักแชทได้เลย" และเว้นที่ว่างไว้ใส่ชื่อร้าน
- ห้ามวางตัวหนังสือชิดขอบล่างหรือขอบขวา เพราะจะโดนปุ่มของ TikTok บัง
